# Archivo de entregables importados

deliverables/execute/ contiene el paquete recibido y sus revisiones 01_FINAL_V2 y 02_HISTORIAL_V1. La palabra FINAL en esos nombres pertenece al paquete histórico y no declara final el firmware actual. El simulador de 01_FINAL_V2 aún se usa en las pruebas automáticas; por eso se conserva junto con sus archivos.

execute.zip conserva una instantánea anterior de ese paquete: algunos archivos difieren de la carpeta extraída. 03_ORIGINAL_USUARIO contiene otro ZIP de origen. No se eliminaron esos archivos porque no son copias idénticas de las versiones extraídas.

Para trabajar hoy, abrir el [índice](../../docs/INDICE.md), el firmware/casa_inteligente_v4/ y hardware/planos/. Los renders, diseños y simuladores aquí son referencias históricas.
