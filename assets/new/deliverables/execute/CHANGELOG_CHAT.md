# Historial de cambios del chat

## Material recibido

- Repositorio/proyecto original comprimido: `casa_inteligente_v4 (1).zip`.
- Imagen de referencia de la maqueta: `Screenshot_20260901-220639_Docs.jpg`.

## Primera entrega

- Se creó un simulador Python local.
- Se añadieron 13 pruebas automáticas.
- Se creó arquitectura sin Wi-Fi, Bluetooth/BLE, teléfono ni nube.
- Se generaron plano técnico, OBJ/MTL, renders y visor HTML.
- La primera interpretación colocó erróneamente la vivienda en dos plantas.

## Corrección final v2

- Se eliminó por completo la segunda planta, el entrepiso y la escalera del diseño.
- Se rediseñó la casa como un único nivel abierto al frente.
- Se reorganizaron invernadero, vivienda, porche, Jarvis y gabinete según la referencia.
- Se añadieron cocina, sala, dormitorio, baño, muebles, sensores, luces, riego, paneles solares y electrónica.
- Se regeneró el modelo con 99 objetos, 792 vértices y 594 caras.
- Se regeneró el plano técnico acotado en SVG/PDF.
- Se mejoró el visor HTML offline con rotación, zoom, vistas rápidas, capas y selección de piezas.
- Se crearon lista de corte, BOM de componentes y guía de montaje.
- Se validaron sintaxis de Python/JavaScript, PDF, ZIP y 13 pruebas automáticas.
